Features

Everything drawn procedurally in code — no texture files, no asset pipeline.

🪐

Real N-body gravity

Newtonian gravity between all bodies (G = 4π²), kick-drift-kick leapfrog integration, momentum-conserving collisions and merges.

🌟

Procedural bodies

Animated star surfaces, rocky planets, banded gas giants, moons and 400-body asteroid belts — generated in shaders.

⏪

Time machine

Pause, 0.1×–32× speed, and full time reversal — watch orbits run backwards.

🖱️

Orbit camera & picking

Orbit / pan / zoom, click to select, double-click to focus and follow any body.

💾

Presets & save/load

Solar System, Binary star, Star + Moon, Random Universe — and plain-text saves of your whole cosmos.

🖥️

Full in-engine UI

Bottom bar (Add / Tools / Find / Sim / View), time bar and tabbed panels — an immediate-mode GUI drawn on GL quads.

Get it running

Three ways in — all from the same green CI run.

1 · Installer (recommended)

Grab UniverseSandbox3D-Setup-win64 from the Actions artifacts. Installs to C:\Program Files\Universe Sandbox 3D with start-menu + desktop shortcuts and an uninstaller. Fully self-contained (static C runtime).

2 · Portable exe

Download UniverseSandbox3D-exe-msvc-win64 (or the -exe-cross-win64 build), unzip and run us3d.exe. Saves sit next to the exe.

3 · No GPU driver? (VMs)

Use the bundled run_mesa.bat with the Mesa for Windows DLLs (opengl32.dll + libgallium_wgl.dll) next to the exe — software rendering via llvmpipe.

Requirements: Windows 7 SP1 / 10 / 11 64-bit · any GPU with OpenGL 3.3 (or Mesa llvmpipe) · 1 GB RAM.
note: the cross-built exe expects the Universal C Runtime on Windows 7 (any VC++ 2015–2022 redistributable); the installer build has zero runtime prerequisites.

Under the hood

Zero external dependencies — the whole app, loader and installer are first-party.

C++11 · OpenGL 3.3

Hand-rolled WGL context bootstrap (core & compatibility profiles, with a full self-diagnostic dialog) and a self-contained GL 3.3 loader — no GLEW, no GLFW, no frameworks.

Physics

Leapfrog KDK integrator at 512 substeps/s, softening ε = 10⁻⁴, reversible time, collision merge with momentum conservation.
